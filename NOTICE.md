## Network filter SDK — © Vitaly Sidorov

`assets/native/nfapi.dll` and `assets/native/nfdriver.sys` are the user-mode API and kernel
driver of the NetFilter SDK, used by **Process mode** to redirect connections belonging to the
apps you select. The driver is WHQL-signed and runs as the `netfilter2` service.

RouteScope does not modify these binaries and does not reverse-engineer them; it calls the
documented C API. They are included unmodified.

**The SDK is commercially licensed.** It is redistributed here unmodified under GPL-3.0. The
SDK itself is **not** covered by that licence: any use beyond this redistribution requires a
commercial licence from its author. Every other capture mode (App proxy, System proxy, Whole
computer) operates without this driver.
